Design a premium desktop web dashboard called "Raah Operator Console", an AI-powered transit command center for monitoring and managing an entire city's public bus network.

This dashboard is NOT a generic admin panel.

The experience should feel like Uber Mission Control, Tesla Fleet Management, Google Maps Operations, Stripe Dashboard, and Linear.

The UI should communicate confidence, intelligence, and real-time decision making.

Use a clean, minimal, premium design with generous white space, floating cards, subtle gradients, soft shadows, rounded corners, modern charts, and a map-first interface.

Design for Desktop (1440 × 1024).
